# To-Do List App

**Name:** Denise Jasmine A. Bacarro

**Section:** IT3R4


## Program Description
A to-do list app that allows users to add, complete, and delete tasks. It is built using HTML, CSS, and JavaScript.

## How to run
1. Clone or download the repository to your computer.
2. Open the project folder in File Explorer.
3. Double-click 'index.html' to open it in your web browser.
